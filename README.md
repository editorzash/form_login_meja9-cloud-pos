# Form Login — MEJA9 POS Cloud POS

Halaman portal autentikasi & login resmi untuk **MEJA9 POS** (Resto & Table Management).

## Fitur Utama Form Login
1. **Dua Mode Autentikasi**:
   - Mode 1: **Email & Kata Sandi** (dengan fitur intip kata sandi).
   - Mode 2: **PIN Cepat Kasir (6-Digit)** dengan visual dots & virtual numeric keypad layar sentuh.
2. **Akun Demonstrasi 1-Klik**:
   - 👑 **Super Admin / Owner**: `gm@meja9.id` (PIN: `990011`)
   - 💼 **Manajer Operasional**: `captain@meja9.id` (PIN: `223344`)
   - 💳 **Kasir Shift**: `cashier@meja9.id` (PIN: `123456`)
3. **Pemilihan Cabang / Outlet Aktif** (Meja9 Resto Senopati, Meja9 Japanese Dining PIK, Meja9 Bandung).
4. **Indikator Live Status**: Menampilkan status konektivitas server secara interaktif.
5. **Auto Redirect**: Setelah autentikasi berhasil, pengguna langsung diarahkan ke aplikasi utama di [`../meja9-cloud-pos/index.html`](../meja9-cloud-pos/index.html).
6. **Bypass Button**: Tombol shortcut untuk penguji/developer membuka aplikasi tanpa proses login.

## Menjalankan Halaman
Cukup buka file `index.html` langsung di browser Anda (atau via server lokal / GitHub Pages).
